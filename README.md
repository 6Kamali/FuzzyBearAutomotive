# Fuzzy Bear Automotive - Official Website Source

This repository contains the complete source code, assets, and configuration for the **Fuzzy Bear Automotive** official website, hosted at [fuzzybearauto.ca](https://fuzzybearauto.ca).

## 🐾 About the Project
Fuzzy Bear Automotive is a proudly Canadian, Alexander-based mobile service specializing in high-tech vehicle security, key programming, and advanced diagnostics. Founded in 2021 and backed by **25 years of trade experience** and **Red Seal Certification**, this platform serves as the digital dispatch hub for customers across all of Manitoba.

## 🛠️ Site Architecture
The website is built using a mobile-first, high-performance approach to ensure accessibility even in rural areas with limited connectivity.

* **`index.html`**: The landing page featuring our mission, core services, and Manitoba-wide service scope.
* **`services.html`**: Detailed breakdown of our locksmith and diagnostic capabilities.
* **`about.html`**: Background on our founder, our Red Seal credentials, and our history in Alexander, MB.
* **`areas.html`**: A dedicated guide to our province-wide mobile dispatch coverage.
* **`faq.html`**: Answers to common technical questions regarding smart keys, "All Keys Lost" scenarios, and payment.
* **`contact.html`**: Our primary lead generation tool, integrated with Formspree for instant service requests.

## 🚀 Technical Stack
* **Frontend**: Semantic HTML5, CSS3 (Custom Grid & Flexbox), and Vanilla JavaScript.
* **Typography**: Montserrat (Headings) and Roboto (Body) via Google Fonts.
* **Forms**: Integrated with Formspree (Endpoint: `xlgonrqz`) for serverless contact management.
* **Hosting**: GitHub Pages.

## 📋 Version History
* **v1.0 (Current)**: Full site launch. Removed service plans from navigation to prioritize direct contact. Updated all content to reflect province-wide (Manitoba) mobile coverage.
